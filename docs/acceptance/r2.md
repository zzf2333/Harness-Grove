## 环境与隔离

- macOS，`python3` 3.15.0；只用标准库，无新依赖。
- `$WORK`：`mktemp -d` 出来的临时目录。本记录里所有路径归一化成 `$SRC` / `$WORK`。
- `$SRC`：仓库的**副本**（`cp -R <repo>/tools "$SRC/tools"`），不是开发工作目录；命令从 `$WORK/elsewhere` 跑（无关 cwd）。
- `$WORK/home`：合成 Host 根（`~/.claude`、`~/.codex`、`~/.pi`）；`$WORK/phe`：仓库外的 PHE_HOME；`$WORK/shared/AGENTS.md`：
  三个入口共享的合成指令来源。
- 没有读取或比较开发者本机的 `~/.pi`、`~/.codex`、`~/.claude`、`~/.phe`；会话只有一份合成 JSONL（虚构内容）。
- 批准记录一律带 `note: "测试夹具：合成批准，不代表真实用户同意"`；`source=user` 在这里是**夹具**，不是用户同意。

## 两套写入政策的对照（旧沙箱 vs 产品入口）

旧入口（`tools/change.py`、`tools/release*.py`）的守卫一行未改：`release_deploy.sandbox_roots` 仍拒绝真实 home
及其下 `.claude`、`.codex`、`.pi`、`.phe`、`.agents`、`AI/temper`。产品入口不查这套守卫，用自己的
`ApprovedScope`：只放行「本次计划列明的入口路径（精确匹配）」和「显式 PHE_HOME 产物」，外加原子替换用的同目录
临时链接名。

隔离测试 `tests/test_personalize_cycles.py::ProductScopeTests` 用 `mock.patch.object(release_deploy, "real_home", …)`
把合成 home 变成“真实 home”，不用改路径、也不读本机目录：

| 断言 | 结果 |
|---|---|
| `release_deploy.sandbox_roots(<合成 home>, …)`、`.pi`、`<PHE_HOME>` | 都抛 `GuardError`；`refusal_reason(…/.pi/agent/AGENTS.md)` 非空 |
| `change.main(["apply", …])` 在同一身份下 | 退出 2，`home/` 文件指纹前后完全相同 |
| `personalize.main(["preview"…])` / `["apply"…]` 在同一身份下 | 退出 0，入口改指 `<home>/.phe/releases/…`，账本 `source=user` |
| `ApprovedScope.check(<计划内入口>)` / `.check(<home>/.claude/other.md)` | 前者通过，后者抛 `GuardError` |

这条对照说明产品入口不是“临时路径才跑得通”：它按批准的计划写真实形式的路径，范围仍限于计划列明的入口。

## 机器断言覆盖

- 预览只写 `<PHE_HOME>/reports/<cycle>/`，Host 与共享来源字节不变；计划含报告/变更包 sha256、每个入口的形态与
  内容 sha256、每条目的 diff 与前后 sha256、写入范围（`host_writes`）与恢复方式。
- 只批准 P1 时 P2 不生效、不追加账本事实；两条来源分支（`user` / `sandbox_rehearsal`）都按计划写、按账本记，
  记录带夹具说明，没有任何字段把批准或应用写成效果已验证。
- 预览后改变更包、改入口、改目标内容都要求重新预览，且不写 Host、不追加账本。
- 逆序恢复限制、恢复计划绑定、恢复后回到应用前字节、`bindings.json` 复原为空。
- 第二周期读回上一周期 `processed_evidence`（源文件路径 + 行号 + 原文 ts）、三行说明与复盘结论；重复计入旧证据被拒。
- `status` / `review-plan` / `review` 在产品 PHE_HOME 上直接可用，不用旧入口的临时路径限制。

## 未验证 / 剩余缺口

- Host 是否加载或触发这些入口：**未验证**；`review` 只能记 `observe` / `unknown`。
- 安装包、默认 `~/.phe`、安装用户的引导流程：仍未提供（R1 剩余项）。
- 只支持单个 instructions 资产 + 软链入口；普通文件入口、skill/MCP/Hooks（R3）不支持。
- 自动取样、自动判定、按观察窗自动筛会话：没有；由宿主按 `prediction.verify` 与行号指针做。
- 本记录未读真实 Host 配置、未调用 Host、未推送。
